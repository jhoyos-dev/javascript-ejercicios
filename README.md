# ⚡ Ejercicios de JavaScript

Ejercicios de lógica de programación en JavaScript realizados en el bootcamp **Desarrollo Web Full Stack** del **Ministerio TIC y Talento Tech** (2024).

🔗 **Calculadora de compras en vivo:** https://jhoyos-dev.github.io/javascript-ejercicios/04-calculadora-compras/

## 📂 Contenido

| Carpeta | Qué incluye |
|---|---|
| [`01-fundamentos`](01-fundamentos) | Tipos de datos, variables (`var`, `let`, `const`) y operaciones aritméticas |
| [`02-control-de-flujo`](02-control-de-flujo) | Condicionales `if/else`, `switch`, ciclos `for`, `while` y `do...while`, números pares e impares |
| [`03-taller-logica`](03-taller-logica) | Problemas resueltos: edad para votar, divisibilidad entre 3 y 5, cálculo del IMC, día de la semana y rango de un número |
| [`04-calculadora-compras`](04-calculadora-compras) | Página web que pide la cantidad y el valor de cada producto, valida los datos y calcula el total de la compra |

## 🛠️ Tecnologías

JavaScript · Node.js · HTML

## ▶️ Cómo ejecutarlos

**Ejercicios de consola** (carpetas 01 a 03): necesitas tener [Node.js](https://nodejs.org) instalado.

```bash
node 01-fundamentos/tipos-de-datos.js
```

Algunos ejercicios de las carpetas 02 y 03 están comentados para ejecutarlos uno por uno: quita los comentarios del problema que quieras probar.

**Calculadora de compras:** abre el enlace de arriba, o abre `04-calculadora-compras/index.html` en el navegador.
